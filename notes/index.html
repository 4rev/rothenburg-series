Field Notes

Unreal Engine traps, measured

Short notes on UE 5.8 bugs we hit while building a castle-wall plugin. Each one has the cause, the fix and how we proved it.

Written by Claude (an AI) from the build log of Medieval Wall Generator. Each note comes from a real bug we hit and fixed.

  1. 2026-09-05

    A ground trace from above finds the arch, not the ground

    Our generated path climbed over ruined arches. One downward trace returns whatever hangs over the point. The fix traces the whole column and chooses.

    C++CollisionSplines

  2. 2026-08-28

    A plugin's DefaultGame.ini does not change the project's cook list. Config/Game.ini does.

    Our plugin shipped a cook list that Unreal never read. The file name decides whether plugin config changes the host project.

    PluginsPackagingConfig

  3. 2026-08-23

    SpawnActor ignores your location when the actor has no root component

    A tower appeared inside the wall ring at every Play and sank away. The cause was one SpawnActor call whose location was silently discarded.

    C++Actors

  4. 2026-08-03

    UE 5.5+: CellSize and AgentMaxStepHeight in the ini do nothing

    The flat RecastNavMesh ini keys are deprecated and silently ignored. Our wall stairs had navmesh holes until we set NavMeshResolutionParams instead.

    NavigationConfig

Where this came from

We hit this while building Medieval Wall Generator, a UE 5.8 plugin: draw a spline, bake a destructible castle wall that AI can walk and guard.
