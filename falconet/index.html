Falconet Cannon

Playable black-powder artillery for Unreal Engine 5.8. This page is the README that ships inside the plugin.

Overview

A playable historical falconet (small field cannon): animated carriage, real projectile, recoil, powder smoke, muzzle flash and distance-aware audio. C++ runtime plugin for Unreal Engine 5.8, Win64.

Quick start

  1. Copy Falconet into your project's Plugins folder (or install it from Fab).
  2. Enable Falconet Cannon in Edit > Plugins and restart the editor.
  3. Content Browser > Settings > Show Plugin Content.
  4. Open /Falconet/Demo/Maps/FalconetDemo and press Play.

Demo controls

  • WASD + mouse: fly. E / Q: up / down.
  • C near the cannon: man it. C again: leave.
  • While manning: mouse aims, left click fires.
  • The targets take standard Unreal point damage.

The demo map sets its own GameMode (FalconetDemoGameMode), so your project settings are not changed.

Using the cannon in your game

Place /Falconet/Blueprints/BP_FalconetCannon in a level. Drive it from your own input, AI or Blueprint:

  • Fire (respects FireCooldown), AddTraverse, AddElevation.
  • StartAutoFire / StopAutoFire for timed firing.
  • Set the cannon's Instigator so damage credit reaches the right controller.

No custom GameMode, input mapping, player controller or collision channel is needed. BP_Falconet (Blueprints/Falconet) is the static model only.

What it does

  • Five-part cannon model with its own materials and textures.
  • Barrel elevation with a moving quoin (wedge), carriage traverse, wheel roll.
  • Recoil run-back, barrel jump and return to battery.
  • Niagara powder smoke and sparks, muzzle flash light, camera shake.
  • Cannon report and impact sounds with distance delay and attenuation.
  • Ballistic cannonball: gravity, ricochet off shallow hits, damage scaled by impact energy.
  • Optional impulse for Chaos Geometry Collections (needs a fractured collection with thresholds).

All settings (sounds, effects, meshes, recoil, light, aim limits) are editable in Details. Idle cannons do not tick. Single-player; replication is not included.

Packaging

Config/Game.ini adds /Falconet to the cook list of the host project, so content that the C++ code loads by path is cooked automatically.
